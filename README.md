# EVE MB30 4S2P Battery Hardware

Parametric CAD development of mechanical hardware for an EVE MB30 4S2P LiFePO4 battery bank.

## Project

The project is designed around EVE MB30 306 Ah prismatic LiFePO4 cells with double-hole M6 terminal studs.

The CAD system is being developed to provide:

- Cell mounting
- Busbar mounting and insulation
- Fuse mounting
- Positive and negative cable terminals
- Protection against accidental contact with live busbars and terminals
- Mechanical support for high-current connections
- Parametric cell and battery-bank geometry
- Complete 4S2P battery-bank assembly

## CAD

Primary CAD software:

- FreeCAD 1.0

The MB30 cell model is parametrically driven from a FreeCAD spreadsheet containing measured dimensions of the physical cells.
